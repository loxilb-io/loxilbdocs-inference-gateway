# Security Policy

## Reporting a Vulnerability

This repository contains documentation. If you find a security issue in the documented product
— the [loxilb-inference-gateway](https://github.com/loxilb-io/loxilb-inference-gateway) — or in
this documentation (for example, an example that leaks a credential or teaches an insecure
configuration), please report it privately.

Email **[loxilb-devel@netlox.io](mailto:loxilb-devel@netlox.io)** with:

- a description of the issue and its impact,
- the affected page(s) or component, and
- steps to reproduce, if applicable.

You will receive an acknowledgement within 48 hours. Please do **not** open a public issue or
pull request for security matters until we have coordinated a fix.

## Scope

- **Documentation content** — insecure examples, leaked secrets, or misleading security guidance
  in this repository.
- **Product vulnerabilities** — for issues in the gateway itself, reports are forwarded to the
  core maintainers of the code repository.

For general questions that are not security-sensitive, use the
[LoxiLB Slack community](https://www.loxilb.io/members).
