    Prove deletion and restore the single-host lab¶

    Verify the surviving boundary and revoked credential before owner-checked infrastructure teardown.

    Continue in the same lab

    Use the same root Bash session from setup. Follow the common evidence and rollback conventions throughout the exercises.

    Prerequisites and owner checks¶

    Finish recovery and restore the owned DB first. Save all result files before stopping fixtures. Read active.json and compare its owner and exact names with live resources. The CICD guard checks all containers plus network endpoints before mutating any; a foreign endpoint must cause refusal. Never use broad prune, down -v, host sysctl/kernel changes or reboot as cleanup.

    Lift controls and verify a surviving source fence¶

    Remove B blacklist, D operator firewall and security-rate policy. D is allowed by the remaining A/C/D fence and must recover. Create a matching plain alias, delete only that alias, then require B still denied and A delivered through the survivor. Delete the last source-fenced primary only after this check. The complete LB key includes host/VIP/port/protocol/model (and path if configured).

    docker exec uc7-gw curl -sS --max-time 20 --config /etc/loxilb/control.curl -X DELETE -w '\nHTTP:%{http_code}\n' "$API/config/ipfilter?filterType=blacklist&cidr=192.0.2.51/32"
docker exec uc7-gw curl -sS --max-time 20 --config /etc/loxilb/control.curl -X DELETE -w '\nHTTP:%{http_code}\n' "$API/config/firewall?sourceIP=192.0.2.53/32&destinationIP=192.0.2.10/32&minDestinationPort=8080&maxDestinationPort=8080&protocol=6&preference=65010"
docker exec uc7-gw curl -sS --max-time 20 --config /etc/loxilb/control.curl -X DELETE -w '\nHTTP:%{http_code}\n' "$API/config/securityrate"
sleep 2
docker exec -i uc7-d curl -sS --http1.1 --connect-timeout 2 --max-time 6 --config /run/edge-key.curl -H 'Content-Type: application/json' -H "X-Edge-Nonce: $RUN-lift-fw" --data-binary @- -w '\nHTTP:%{http_code} VERSION:%{http_version}\n' "http://$VIP:8080/v1/completions" < "$LAB/request.json" > "$LAB/lift-fw.txt" 2> "$LAB/lift-fw.err"

    Stop the publisher and tear down only owned infrastructure¶

    Compare PID/start time before signalling. If it has already exited, record that fact rather than killing a reused PID. Then call the same pinned CICD teardown from the same SRC and EDGE_STATE. It preserves evidence, images and the private DB bind directory, and supports partial-failure cleanup.

    if test -n "${PUB_PID:-}" && test -r "/proc/$PUB_PID/stat"; then
  test "$(awk '{print $22}' "/proc/$PUB_PID/stat")" = "$PUB_TICK" && kill "$PUB_PID"
fi
wait "${PUB_PID:-}" 2>/dev/null || true
EDGE_STATE="$EDGE_STATE" bash "$SRC/cicd/edge-cloud-security/rmconfig.sh"
EDGE_STATE="$EDGE_STATE" bash "$SRC/cicd/edge-cloud-security/rmconfig.sh"
docker ps -a --no-trunc --format '{{.ID}} {{.Names}} {{.State}}' | sort > "$WORK/containers-after.txt"
cmp "$WORK/containers-before.txt" "$WORK/containers-after.txt"
docker network ls
jq '{status,owner}' "$EDGE_STATE/active.json"
unset KEY_ID SECOND_KEY_ID CONTROL_KEY_ID PUB_PID PUB_TICK EP_PID

    Expected cleaned state, no owned containers/network, repeat cleanup success and unchanged foreign container IDs/names/states. Inspect the recorded preflight network/routes too. Build images and private evidence are deliberately retained; this is not a disk-wipe procedure. Do not delete secrets or snapshots from another run. New config.sh starts a fresh DB/run after the old one is cleaned.

    Troubleshooting and result record¶

    A refused ownership guard means inspect the conflicting endpoint/label and stop. Do not remove an unidentified object to get a green cleanup. A missing process/metric/journal is not a zero/PASS. For each case retain source/eBPF/image/binary, document/input hashes, kernel, command and timestamp, HTTP status/version/exit, GET/effective, nonce/receipt, owning delta, failures, recovery and cleanup. Keep raw logs, snapshots, DB data and credentials private; share only reviewed allow-listed summaries.
