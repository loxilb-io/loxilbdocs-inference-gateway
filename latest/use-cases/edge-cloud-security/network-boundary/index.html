    Fence a shared service and verify peer deletion¶

    Distinguish an explicit TC drop from the source policy shared by models on one listener.

    Continue in the same lab

    Use the same root Bash session from setup. Follow the common evidence and rollback conventions throughout the exercises.

    Before you start¶

    Remove prior source controls before isolating this layer.

    Focus of this page: Change service-scoped source fences and the operator TC firewall at the shared VIP.

    Topology and execution locations¶

    flowchart TD
    C["Client containers<br/>A .50 / B .51 / C .52 / D .53"] -->|"inference 8080"| G["uc7-gw<br/>192.0.2.10"]
    G -->|"HTTP 80"| E["uc7-ep<br/>192.0.2.21"]
    G -.->|"store 5432"| P["uc7-pg<br/>192.0.2.30"]
    O["Host Bash<br/>private LAB files"] -.->|"docker exec: localhost API 11111"| G
    O -.->|"nonce journal and receipt"| E
    E -.->|"optional synthetic KV events 5557"| G
    style G fill:#e1f5fe,stroke:#0288d1,color:#1f2937
    style E fill:#e8f5e9,stroke:#43a047,color:#1f2937
    style P fill:#fff3e0,stroke:#fb8c00,color:#1f2937

    All seven containers are on the isolated Docker network 192.0.2.0/24; they are not seven physical machines. No host port is published. A host localhost curl cannot replace docker exec into uc7-gw. Source and service protections act before the request reaches the CPU backend.

    Where What happens here
    Host root Bash Own WORK/LAB, lifecycle inputs and private curl credential files.
    uc7-a / b / c / d Send source-specific traffic; preserve the A/B/C/D roles in each experiment.
    uc7-gw Run REST curl against localhost:11111 inside the container; enforce controls on inference 8080.
    uc7-ep Keep the nonce journal, direct backend observations and optional synthetic KV publisher.
    uc7-pg Store policy/keys on .30; interrupt it only in the recovery chapter.

    Walkthrough¶

    Prerequisites and TC baseline¶

    Remove source controls first. The plain baseline lets D reach the backend before the operator drop. Firewall protocol:6 means TCP; zero ports mean wildcard, so specify both ends of this destination port range. preference participates in the rule identity and precedence;65010 precedes the generated shared-listener allow65000. Do not use duplicate POST as an update.

    Configure two models on one source-fenced listener¶

    Source policy belongs to normalized VIP/port/protocol, not to an HTTP model name. Allow A/C/D, exclude B, and give both peer rules identical prefixes. Save the original writable plain rule.

    Step 1 — Check the next precondition

    Run these commands in order and stop if a check fails. Keep the original inputs and results available for diagnosis before making the next change.

    cp "$LAB/model.json" "$LAB/plain-model.json"

    Troubleshooting¶

    A new model name on the same listener does not grant a different network boundary. An earlier operator drop can continue denying a source allowed by allowedSources. Check CIDR normalization, priority, full deletion tuple and other installed layers before diagnosing a policy error.

    Check your result¶

    An ACL refusal must preserve unrelated model/service traffic and have no backend delivery.

    Keep a normal control request alongside each denied or interrupted request. Separate packet drop, TCP refusal, HTTP denial, backend receipt, and counter changes. Readback establishes stored policy; client traffic and the backend journal establish delivery.

    Next steps and cleanup¶

    Remove the isolated control before adding the next layer. Recovery restores the complete owned tuple; final cleanup uses the recorded ownership state and must preserve unrelated containers. Read the lab starting point if required values are missing. Use cleanup and recovery when ending the run.
