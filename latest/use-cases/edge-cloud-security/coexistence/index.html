    Keep routing and streaming working with the controls enabled¶

    Combine proven layers and retain independent normal delivery, protocol and routing observations.

    Continue in the same lab

    Use the same root Bash session from setup. Follow the common evidence and rollback conventions throughout the exercises.

    Before you start¶

    Complete isolated controls and restore the baseline before combining their exact tuple.

    Focus of this page: Add synthetic KV events and retain H2/SSE delivery with all selected protections enabled.

    Topology and execution locations¶

    All seven containers are on the isolated Docker network 192.0.2.0/24; they are not seven physical machines. No host port is published. A host localhost curl cannot replace docker exec into uc7-gw. Source and service protections act before the request reaches the CPU backend.

    Where What happens here
    Host root Bash Own WORK/LAB, lifecycle inputs and private curl credential files.
    uc7-a / b / c / d Send source-specific traffic; preserve the A/B/C/D roles in each experiment.
    uc7-gw Run REST curl against localhost:11111 inside the container; enforce controls on inference 8080.
    uc7-ep Keep the nonce journal, direct backend observations and optional synthetic KV publisher.
    uc7-pg Store policy/keys on .30; interrupt it only in the recovery chapter.

    Walkthrough¶

    Prerequisites: one explicit tuple¶

    Complete isolated controls and restore their baseline state. This chapter deliberately combines A/C/D allowedSources, B blacklist, D operator TC drop, source rate10/5/100, keyRPS1/burst1, listener slots4/process context bound16 and synthetic KV/H2/SSE. C is allowed by the fence and may be rate limited; B is never an alternate normal control. Do not mix another campaign's source roles. Byte-shaper performance is covered by QoS; it is not added as another bandwidth campaign here.

    Configure synthetic KV and prove a positive baseline¶

    Replace the lab's plain baseline with a fresh KV rule: delete only the owned full key, then create its KV configuration as shown below. Keep the publisher, inventory, positive hit delta and independent backend receipt checks together. A policy POST or effective label alone does not establish routing.

    Use the fixed tokenizer/corpus prepared by CICD. Model name, request prompt bytes, tokenizer, block16, sha256_cbor and seed0 must agree. The source's legacy fixture is explicitly unattested. A routing hit is not real engine reuse. On a source with a migration fence, stop; do not disable its guard. Use profiles/readiness for strict production bindings.
